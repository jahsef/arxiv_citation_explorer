scrape

Walks outward from a seed paper via Semantic Scholar. Jobs run one at a time on a background thread — the rest of the app stays responsive while one is running.

Depth 0 gives the citation graph; 1 is needed for the scatter, which requires the sub-papers' own references to build our 'citation score' from, otherwise no bibliographic coupling score can be computed. Each extra hop costs roughly 40× the requests.

backward · references — the recursive crawl

References are always stored in full — coupling needs complete reference lists on both sides, so this never filters them. The threshold below bounds crawl breadth: only papers with at least this many citations get expanded (their own references fetched). 0 expands everything; raise it to keep a deep crawl converging on foundational papers instead of exploding into thousands of low-cite ones.

forward · citations

Citers = papers that cite the seed (references, above, are papers the seed cites). Fetched for the seed only, not during the recursive crawl. S2 returns newest first, capped by max records and thresholded by the citer's own citation count.
