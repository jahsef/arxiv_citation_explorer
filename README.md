ArXiv citation explorer



DEMO: https://youtu.be/4fejbXFDYps



\*\* Technical Description



Recursively scrapes ArXiv id's using semantic scholar API. 



Supports semantic search of abstracts and string matching of paper titles. 



Visualizes paper's connections with a normal citation graph, and also supports 2d visualization using these metrics: semantic similarity of abstracts, bibliometric couppling (citation similarity), and cocitation rate.
